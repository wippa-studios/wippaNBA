# Code of conduct

This repository adopts the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating, you are expected to uphold it.

## Enforcement

Report unacceptable behaviour to the repository maintainers through GitHub —
for example by opening an issue on this repository or by contacting the
`wippa-studios` organisation. Do not route conduct reports through the security
reporting channel. The maintainers will review and respond on a best-effort
basis; there is no guaranteed response time.
